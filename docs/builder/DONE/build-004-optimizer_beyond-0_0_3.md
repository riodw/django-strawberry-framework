### The read-only correctness audit — findings

All eight slices were verified present and behaviourally coherent. **No defect found.** Five observations, recorded so R2 does not mistake any of them for drift to "fix":

1. **B1's key is collision-safe by construction, not by hash luck.** Storing the printed AST string rather than `hash(document)` is a deliberate rejection of the spec's own pseudo-code, and the docstring says why. The five components each close a distinct collision class (fragment bodies, model, root field identity, resolver origin). Correct as designed.
2. **`cache_info().misses` deliberately does not count execution-memo hits.** An intra-execution reuse of an uncacheable plan touches neither counter, so `misses` reads as "actual walker builds". A reader expecting `lru_cache` semantics would call this wrong; it is documented and intentional.
3. **`_plan_cache` is mutated without a lock and that is a stated, bounded trade.** `cache_info`'s docstring names both failure modes (a dropped `+= 1`, a double-evict) and argues correctness-neutrality: the cache can only lose hit rate, never return wrong data. Correct as designed; a rationale entry, not a spec sentence.
4. **B8's string-upgrade path returns a rewritten queryset, which is why the signature is a 2-tuple.** A reader of the spec's pseudo-code would expect `apply()` on a delta; the real contract has to hand back both halves. Correct as designed.
5. **B6's `(model, field_name)` dedupe is a multi-type artifact, not generic defensiveness.** Its comment says so explicitly, and the audit still walks every reachable type because a secondary may expose a relation the primary hides. Correct as designed.

Two further observations for the deferred-work catalog rather than for R2: the `_record_relation_access`-before-elision ordering invariant in `_plan_select_relation` still has **no automated guard** (carried over unchanged from the spec-003 cycle's audit — reversing the two would silently reintroduce an N+1); and the `check_optimizer` management command B6's test surface names as follow-up work (D21) has never been built, with no card naming it.
